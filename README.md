# Rider-Companion

An intelligent companion for motorcycle riders, combining ride planning, motorcycle management, maintenance tracking, and future AI-powered assistance across Web and Android.

## Monorepo

This repository will be structured as a monorepo managing both the backend and web frontend applications.

## Proposed Technical Architecture

### Backend

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- JWT
- PostgreSQL
- Liquibase
- Maven
- Swagger / OpenAPI

### Web App

- React
- TypeScript
- Vite
- React Router
- Axios or Fetch API
- React Hook Form
- Material UI
