A visual walkthrough of how a Motorcycle API moves from an HTTP request to a database row and back to a JSON response.

The five layers

Each layer has one responsibility. The controller does not access the database directly; it delegates to the service, which delegates to the repository.

1. ClientBrowser, mobile app, Postman or curl sends JSON over HTTP.
2. ControllerMaps URL + HTTP method to a Java method.
3. ServiceApplies business rules and coordinates the use case.
4. RepositoryUses JPA to load, save, and delete entities.
5. EntityMaps Java fields to columns in the motorcycles table.

Service — MotorcycleService.java

Contains the use cases and ensures an ID exists before update or delete.

@Service
public class MotorcycleService {
  private final MotorcycleRepository repository;

  public Motorcycle create(Motorcycle motorcycle) {
    motorcycle.setId(null);
    return repository.save(motorcycle);
  }
  public List<Motorcycle> findAll() {
    return repository.findAll();
  }
  public Motorcycle findById(Long id) {
    return repository.findById(id)
      .orElseThrow(() -> new MotorcycleNotFoundException(id));
  }
  public Motorcycle update(Long id, Motorcycle input) {
    Motorcycle current = findById(id);
    current.setBrand(input.getBrand());
    current.setModel(input.getModel());
    current.setYear(input.getYear());
    return repository.save(current);
  }
  public void delete(Long id) {
    if (!repository.existsById(id)) throw new MotorcycleNotFoundException(id);
    repository.deleteById(id);
  }
}

Controller — MotorcycleController.java

Exposes service use cases as HTTP endpoints.

@RestController
@RequestMapping("/api/motorcycles")
public class MotorcycleController {
  private final MotorcycleService service;

  @PostMapping @ResponseStatus(CREATED)
  Motorcycle create(@RequestBody Motorcycle body) { return service.create(body); }
  @GetMapping List<Motorcycle> all() { return service.findAll(); }
  @GetMapping("/{id}") Motorcycle one(@PathVariable Long id) { return service.findById(id); }
  @PutMapping("/{id}") Motorcycle update(@PathVariable Long id, @RequestBody Motorcycle body) { return service.update(id, body); }
  @DeleteMapping("/{id}") @ResponseStatus(NO_CONTENT)
  void delete(@PathVariable Long id) { service.delete(id); }
}
